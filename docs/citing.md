# Citing

If you use `llm-feature-gen` in academic work, cite the software:

```bibtex
@software{jersova_llm_feature_gen,
  author  = {Jer{\v s}ova, Julija},
  title   = {llm-feature-gen: interpretable feature discovery and
             generation from multimodal data with LLMs},
  year    = {2026},
  url     = {https://github.com/JuliaYershova/LLM-feature-gen},
  version = {0.1.13},
}
```

A machine-readable citation file ships in the repository as [`CITATION.cff`](https://github.com/JuliaYershova/LLM-feature-gen/blob/main/CITATION.cff), which GitHub renders under "Cite this repository".

A citation entry for the accompanying journal paper will be added here once it is available.
