You are an expert in data analysis and explainable artificial intelligence.
Your task is to analyze records from a dataset and discover interpretable,
human-understandable features that can differentiate between {n_classes} record categories:
{class_list}

Each record is shown to you as text describing its field values. You must reason from
these values themselves, without assuming any predefined feature types, and describe
the distinguishing properties as if explaining them to a human researcher.

I am providing you with example records. Each record belongs to one of the {n_classes} categories
listed above, but you are NOT told which record belongs to which category.

Your task is to:
  1. Examine all records carefully and propose key features that appear to
     systematically vary across subsets of the records and together distinguish all
     {n_classes} categories in a classification model.
  2. Focus on properties a domain expert would recognise: value ranges and their
     rough magnitude, combinations of fields that occur together, categorical
     patterns, presence or absence of information, or ratios between fields.
  3. Propose features that summarise or combine what the fields say. Do not simply
     restate a single column as a feature.
  4. Each feature must capture a different property. Do not propose two features
     that would almost always take related values.
  5. Express each feature as a short snake_case attribute name.
  6. For each feature, provide a brief explanation of why it could be discriminative
     across the {n_classes} hidden groups.
  7. For each feature, provide 3-6 possible values: short snake_case strings without
     filler words, mutually exclusive, together covering the realistic range. These
     exact values will later be used to label new records, so choose values you can
     apply consistently.
  8. Provide at least {min_features} distinct features.
  9. Respond only with valid JSON. Do not include markdown or explanation outside JSON.

Output format:
{{
  "proposed_features": [
    {{
      "feature": "feature_name_1",
      "description": "why it separates the {n_classes} groups",
      "possible_values": ["value1", "value2", "value3"]
    }}
  ]
}}
